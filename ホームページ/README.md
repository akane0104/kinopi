# ぴのきー。サイト

ピンクでかわいいLive2D制作サイトと、実績・モデル・料金を更新する管理画面です。

## すぐに見られるもの

- `index.html` — お客様向けサイト
- `admin.html` — 管理画面

Supabaseをまだ設定していない状態でも、公開サイトには見本の表示と料金シミュレーターが出ます。管理画面を使うには、以下の初回設定だけ行ってください。

## 初回設定（約10分）

1. [Supabase](https://supabase.com/) で無料プロジェクトを作成する。
2. プロジェクトの **SQL Editor** を開き、`supabase/schema.sql` の中身を貼り付けて `Run` する。
3. **Authentication > Users** で、管理用メールアドレスのユーザーを作成する。`Auto Confirm User` をオンにして作成するとすぐログインできます。
4. Dashboard上部の **Connect**、または **Settings > API Keys** から `Project URL` と `Publishable key` をコピーする。古いプロジェクトでは `anon public key` でも動作します。
5. `config.js` の `url` と `anonKey` に貼り付けて保存する。

`Publishable key`（または旧 `anon public key`）は公開サイトに置くためのキーです。**`sb_secret_...` や `service_role key` は絶対に `config.js` に貼らないでください。**

この後は `admin.html` からログインし、実績、モデル紹介、トップの画像・動画、クーポン、価格、オプションを更新できます。画像・動画はURL入力か、管理画面でのファイルアップロードに対応しています。

すでに以前の `schema.sql` を実行済みの場合も、更新後のファイルをもう一度SQL Editorで実行してください。既存の「舌出し・横顔まで制作」が「舌出し」と「横顔まで制作」の二つの管理項目に分かれます。

相談受付BOXを使うには `supabase/inquiries-faqs.sql` を実行してください。さらに、返信管理・メモ・メール送信機能を使うには `supabase/inquiries-status-columns.sql` も実行してください（既存の相談データには影響しません）。 連絡方法（X・Discord）とキャンセル管理・プラン編集機能を使うには、さらに `supabase/inquiries-contact-status.sql` を実行してください（既存の相談データには影響しません）。 完成モデル販売セクションを使うには `supabase/products.sql` も実行してください。 依頼管理（ステータス・納期・進捗・修正・支払い・ファイル）を使うには `supabase/order-management.sql` も実行してください。 工程別進捗・工程別支払い・工程別修正・相談連携を使うには `supabase/process-management.sql` も実行してください。 依頼者向けの進捗確認ページを使うには `supabase/client-status.sql` も実行してください。 依頼BOXで「イラスト制作・キャラクターデザインが必要かどうか」を表示するには `supabase/request-scope.sql` も実行してください（このSQLを実行した後に届いた新しい相談から反映されます。それより前の相談は「不明（旧フォームの相談）」と表示されます）。

## 見積りフォームについて

「イラストからお願いしたい」「キャラクターデザインもおまかせ」のチェックは、初期状態では**どちらも未選択**です。ご自身の素材（絵・キャラクターデザイン）を持っているお客様が、意図せず追加料金込みで見積りされてしまわないようにするためです。必要な方は、フォーム上でご自身でチェックしていただく形になります。

## 追加機能（依頼BOX）

1. **依頼者用 進捗確認ページ**（`status.html`）— シリアルナンバーを入れると、依頼者本人が自分の進捗だけを確認できます。メール・メモ・金額の内訳は表示されません。使うには `supabase/client-status.sql` を実行してください。
2. **工程テンプレート** — 管理画面トップ「基本設定・トップ表示」の「工程テンプレート」欄に、よく使う工程構成を登録しておくと、依頼BOXの「工程」タブからワンクリックで一括登録できます。書き方は入力欄のプレースホルダーを参照してください。
3. **定型文コピー** — 依頼の詳細画面に「テンプレ文」タブを追加しました。依頼名・シリアル・納期・金額などを自動で差し込んだ文面をワンタップでコピーできます。テンプレートの内容は、管理画面トップの「基本設定・トップ表示」の「定型文テンプレート」欄から、増やしたり書き換えたりできます（空欄のままなら、最初から用意された5つがそのまま使われます）。
4. **納期カレンダー** — 依頼BOXのダッシュボードに月表示のカレンダーを追加しました。日付をタップするとその日が納期の依頼が並びます。1日に3件以上重なるとオレンジ色で警告表示されます。
5. **受付枠のON/OFF** — 管理画面トップの「基本設定・トップ表示」に「新規のご依頼を受け付ける」トグルがあります。オフにすると公開サイトの相談ボタンが押せなくなり、案内文が表示されます。
6. **売上CSV／全データJSONエクスポート** — 依頼BOXの売上ダッシュボードから、入金済みデータのCSV書き出しと、依頼・工程・作業・修正履歴すべてのJSONバックアップができます。
7. **あとからのオプション追加** — 依頼詳細の「契約内容」タブに「カタログから追加」の選択欄を用意しました。管理画面で登録した料金・オプション（「料金・オプション」で追加したもの）や「イラスト制作」「キャラクターデザイン」をそこから選んで追加すると、追加料金として合計に反映され、依頼カードの「イラスト制作：必要／不要」表示も自動で更新されます。もちろん自由入力での追加もできます。

## 追加機能（第2弾）

1. **Discord通知** — 新しい依頼が届いたとき、また依頼のステータスを「納品」「完了」に変更したときに、Discordへ自動でお知らせが送れます。管理画面トップ「基本設定・トップ表示」の一番下にある「Discord Webhook URL」に、Discordのチャンネル設定→連携サービス→ウェブフックから発行したURLを貼り付けてください。空欄なら何も送信されません。
   - ⚠ ご注意：このURLはブラウザ側のコード内に保存され、通知はブラウザから直接Discordへ送信される仕組みです。URLが外部に漏れるといたずら送信をされる可能性があるため、他人と共有しないでください。もし変な通知が届くようになった場合は、Discord側でウェブフックを削除し、新しく発行し直してください（サイト側の設定も更新すれば復旧します）。
2. **特定商取引法に基づく表記** — 公開ページは `tokushoho.html`（トップページのフッターからもリンクしています）。内容は管理画面トップの「特定商取引法」から編集できます。`supabase/reviews.sql` 同様、既存のテーブルには影響しません（`site_settings`に項目が増えるだけです）。空欄の項目は表示されません。
3. **SNSでシェアされたときの見え方（OGP）** — `index.html` の `<head>` に og:title・og:image などのメタタグを追加しました。**サイトを公開したら、`og:url` と `og:image` の中身（`https://example.com/...` の部分）を、実際のドメイン・画像URLに書き換えてください**（コメントの近くにあります）。画像は横1200×縦630px程度がおすすめです。
4. **お客様の声** — 納品後にいただいた感想を、管理画面「お客様の声」から登録できます。「公開する」をオンにしたものだけが、公開サイトの「お客様の声」セクションに表示されます（1件も無い間はセクションごと非表示になります）。使うには `supabase/reviews.sql` を実行してください。
5. **favicon** — 全ページにハート🩷（公開ページ）・歯車⚙️（管理画面）の絵文字favicoファビコンを追加しました。画像ファイルは使わず、コードの中に直接埋め込んでいるので追加の準備は不要です。

自動メール送信（ステータス変更時にお客様へ自動でメールする機能）は、Supabase Edge Functionsと外部メール配信サービス（Resend など）の連携が必要な、少し大きめの追加作業になります。ご希望があれば、次のステップとして相談しながら進められます。

## 追加で実行が必要なSQLファイル（第2弾）

- `supabase/reviews.sql`（お客様の声のテーブルを新規作成。既存テーブルには影響しません）
- `supabase/illustration-request.sql`（依頼フォームのテーブルと確認用の関数を新規作成。既存テーブルには影響しません）
- `supabase/parts-request.sql`（パーツ分け制作フォームに対応するための列を追加。ADD COLUMN IF NOT EXISTS のみで、既存データには影響しません）
- `supabase/illustform-viewed.sql`（依頼票の既読管理のための列を追加。ADD COLUMN IF NOT EXISTS のみで、既存データには影響しません）

## 依頼フォーム（イラスト制作・パーツ分け制作）

「イラストからお願いしたい」「パーツ分けからお願いしたい」を選んだお客様に、詳しいヒアリングをするための専用フォームです。1つのページで、お客様コードを入力したあとに「イラスト制作」「パーツ分け制作」のどちらに回答するかを選んでもらえます。

- 公開ページ：`illustration-request.html`
- お客様は、依頼BOXで発行されたシリアルナンバーを「お客様コード」として入力してからフォームに回答します（本人確認と、依頼BOXへの自動振り分けを兼ねています）
- 回答は依頼BOXの依頼詳細「依頼票」タブに、どちらのフォームに答えたかが分かるバッジ付きで届きます
- 質問の内容は、管理画面「依頼フォーム（イラスト・パーツ分け）」から、Googleフォームのような画面で編集できます。「イラスト制作フォーム」「パーツ分け制作フォーム」をタブで切り替えながら、質問の追加・削除・並び替え・必須回答の切り替え・選択肢の編集ができます。使える回答形式は次の4つです。
  - 一行テキスト
  - 複数行テキスト
  - 単一選択（1つだけ選べる）
  - 複数選択（いくつでも選べる）
  - セクション区切り（「01 基本情報」のような見出しを挟めます）
- お客様への案内メッセージは、依頼BOXの「テンプレ文」タブに「依頼フォームのご案内」として用意してあります（コピーするとシリアルナンバーが自動で差し込まれます）

- 依頼票が届くと、依頼BOXの一覧にオレンジ色の大きなバナーが表示され、「今日やること」にも一番上の優先タスクとして表示されます。依頼詳細を開いて内容を確認すると、既読になってバナー・タスクの両方から自動で消えます
- 納期カレンダーは、初期状態では閉じています。タイトル部分をタップすると開閉できます

使うには `supabase/illustration-request.sql` と `supabase/parts-request.sql`、`supabase/illustform-viewed.sql` を実行してください。

### 編集はどこから？

質問の追加・編集は、管理画面（`admin.html`）から行います。公開サイト上に鍵付きの編集画面を別途作ることも考えましたが、ブラウザに保存したパスワードは開発者ツールで読まれてしまう可能性があり、本当の安全対策にはなりません。すでにログイン機能（Supabase Auth）を備えた管理画面に集約したほうが、安全でかつ管理する場所も一つで済みます。


## 料金の初期設定

| 項目 | 初期価格 |
| --- | ---: |
| プチプラン（上半身） | ¥20,000〜 |
| スタンダードプラン（全身） | ¥40,000〜 |
| 低可動域 | +¥30,000 |
| 高可動域 | +¥50,000 |
| クーポン | 合計から30% OFF |

イラスト制作と価格未定の追加オプションは「要お見積り」と表示されます。管理画面の「料金・オプション」から価格を入れると、シミュレーターの合計にも自動で反映されます。

## 公開方法

静的サイトなので、Netlify、Vercel、GitHub Pagesなどにこのフォルダーの内容をアップロードすれば公開できます。公開後も、`admin.html` で保存したコンテンツはSupabase経由で即時反映されます。
